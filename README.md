# 战术轮盘 Tactical Requests 0.6.25

《杀戮尖塔 2》队伍交流 MOD，作者与维护账户为 Wangy-szu。

## 安装

1. 退出游戏，解压 `TacticalRequests-0.6.25.zip`。
2. 将 `TacticalRequests` 文件夹放入游戏安装目录的 `mods` 文件夹。更新时覆盖旧版文件。
3. 确认文件位于 `mods/TacticalRequests/TacticalRequests.dll` 和 `mods/TacticalRequests/TacticalRequests.json`。
4. 启动游戏并确认 MOD 已加载。主机和所有队友安装相同版本，并保持其他联机 MOD 配置一致。

本版按 Windows 游戏 0.111.0 制作。使用自动读档联动时，全员另外安装 QuickSL 0.3.6-beta。

## 功能

### 战术轮盘与回应

- 未选牌、未瞄准时，点击怪物打开 6 项敌方指令，点击自己打开 8 项自身需求。
- 怪物默认指令为集火、易伤、虚弱、降力、协作增伤和先别攻击。
- 自身默认需求为申请 SL、格挡、力量、抽牌、能量、治疗、敏捷和爆发支援。
- 右键点击指令，或按 Shift 加对应格子的按键，替换轮盘内容。备选包含挡伤、补充手牌、等离子、灵魂、打破格挡和爆发输出。
- 请求显示在目标附近，队友可直接点击回应。多人对同一怪物提出相同需求时合并显示，发起人可撤销申请或确认已满足。
- 玩家身份使用固定队伍颜色，P1 蓝、P2 橙、P3 紫、P4 绿。悬停可查看昵称和回应详情，收到回应时有文字和音效提示。
- 队友确认集火或实际攻击目标后显示红色准心，攻击后收起集火申请。准心跨回合保留至目标死亡或切换集火目标。
- 易伤、虚弱、降力和增伤申请，在队友实际施加或增强对应有效效果后自动收起。其他需求支持手动确认。
- 怪物请求避让意图、血条和伤害数字。请求文字与回应按钮采用“回合结束”的显示字号。

### 默认快捷键

可在主菜单或战斗左下角“按键设置”中修改。

| 按键 | 功能 |
|---|---|
| Ctrl+Q | 打开自己的轮盘 |
| Ctrl+W | 打开鼠标所在怪物的轮盘 |
| Ctrl+R | 切换当前回应的申请 |
| Ctrl+1 | 我来／好的／同意 |
| Ctrl+2 | 做不到／打打看，非战斗 SL 为我比较好 |
| Ctrl+3 | 等一下，集火为想一下 |
| Ctrl+H | 查看队友手牌和药水 |
| 1–8 | 发送已打开轮盘中的对应指令，怪物使用 1–6 |
| Shift 加格子按键 | 替换该格指令 |
| Esc | 收起轮盘、替换列表或手牌面板 |

### 队友手牌与药水

- 点击队友人物打开速览，点击其他队友切换，再次点击同一队友或按 Esc 收起。
- 手牌增加时自动提高牌面重叠，悬停抬起卡牌，点击牌面打开原版详情并查看升级效果。
- 药水显示在面板标题栏，悬停图标查看名称和效果。自己的药水操作菜单显示在展开的手牌面板上方。
- 按住标题拖动整个面板，本机记住位置。刷新、重开和窗口尺寸变化时自动适配屏幕边界。

### 文字聊天

- 点击左下角“聊天”展开输入框，Enter 发送，Esc 收起。
- 昵称和 P 编号对应玩家颜色，正文使用浅色。每条最多 160 字符，保留本局最近 80 条消息。
- 收到队友消息播放短双音提示。面板收起时显示未读数和短暂消息预览。
- 勾选“关联当前申请”后，消息附带当前回应目标与需求，方便补充战术说明。

### SL 申请与联动

- 战斗自身轮盘提供申请 SL。奖励、卡牌奖励、普通事件和先古事件界面也可申请。
- 非战斗 SL 回应为同意、等一下、我比较好，收到请求及新回应时有音效提示。
- 战斗仍在进行时，死亡玩家的自身轮盘仅显示 SL，对存活怪物的指令继续可用。
- 全员安装兼容的 QuickSL 0.3.6-beta 时，发起人视为同意，其余队友全部明确同意后调用 QuickSL 同步读档。
- 兼容检测结果可在非战斗申请区或战斗 SL 请求的悬停说明中查看。缺少兼容版本时仍可交流 SL 意愿。
